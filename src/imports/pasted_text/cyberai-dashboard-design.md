Design a dark-theme cybersecurity dashboard UI for an AI-powered Log Analysis Agent. The product analyzes two types of logs: HDFS system logs and CIC-IDS2017 network flow logs, and detects anomalies using ML/DL models.
Visual style: Dark mode only. Background #0D1117, surface cards #161B22, borders #30363D. Accent color: electric blue #2F81F7 for primary actions and highlights. Red #F85149 for critical alerts, amber #D29922 for warnings, green #3FB950 for normal/healthy. Typography: Inter or JetBrains Mono for data values. Minimal, dense, information-rich layout — inspired by GitHub, Datadog, and Grafana.
Design these 6 screens:
Screen 1 — Main Dashboard
Top navbar with logo "CyberAI Agent", nav links (Dashboard, Alerts, Explorer, Models, Settings), a live status indicator (green dot "Agent Running"), and a user avatar. Below: a 4-column stats bar showing Total Logs Analyzed, Anomalies Detected Today, Active Alerts, and Model Accuracy. Then two side-by-side cards: one for HDFS System Logs (shows a small sparkline of anomaly rate over 24h, last parsed timestamp, and a green/red status badge) and one for Network Flows (same structure). Below that: a full-width area chart showing "Anomaly Rate Over Time" for both pipelines as two overlapping colored lines (blue for network, amber for system). Bottom half: "Recent Critical Alerts" table with columns: Time, Source (HDFS/Network), Attack Type, Severity badge, Confidence %, and an Action button.
Screen 2 — Live Alert Feed
Full-page alert list. Each alert row is a card showing: a colored left border (red=critical, amber=warning, blue=info), an icon for source type (server icon for HDFS, network icon for flows), timestamp, alert title (e.g. "DDoS Attack Detected"), a one-line reason ("Flow Bytes/s 847x above baseline"), severity badge, confidence percentage as a thin progress bar, and two buttons: "Investigate" and "Dismiss". Add filter chips at the top: All / Critical / Network / System / Unreviewed. Show a notification counter badge on the nav.
Screen 3 — Alert Detail Page
Opened when clicking an alert. Left panel (60% width): Alert title and metadata at top (time, source, attack type, confidence score as a circular gauge). Below: "Top Contributing Features" — a horizontal bar chart (SHAP-style) showing the top 8 features with positive contributions in red and negative in blue, each bar labeled with the feature name and value (e.g. "Flow Bytes/s: 1.2M"). Below that: the raw log entry or flow feature table with all 78 values, highlighting the anomalous ones in red. Right panel (40%): "Model Explanation" card describing in plain English why this was flagged. Below: "Similar Past Alerts" list showing 3 related historical events. Bottom: Action buttons — Mark as False Positive, Escalate, Export Report.
Screen 4 — Log Explorer
Search bar at top with filters: Date range picker, Source (HDFS / Network / Both), Status (All / Anomaly / Normal), Severity dropdown. Below: a dense data table with columns: ID, Timestamp, Source, Log Preview (truncated text), Prediction (Normal/Anomaly badge), Confidence, Actions. Each row is clickable. Add a right sidebar that slides in when a row is selected, showing a quick preview of that log's features. Bottom left: a "Submit Log for Analysis" button that opens a modal with a text area to paste a raw log line or JSON flow record.
Screen 5 — Model Performance Panel
Two tabs at top: "System Model (HDFS)" and "Network Model (CIC-IDS2017)". Each tab shows: a 3-column metrics row (Precision, Recall, F1-Score as large number cards with a small trend arrow). Below: a Confusion Matrix heatmap (2x2 for binary: True Positive, False Positive, False Negative, True Negative) with cell values and color intensity. Next to it: a ROC Curve chart (line graph, AUC score labeled). Below: "Feature Importance" — a ranked horizontal bar chart of top 15 features. Bottom: a "Model Drift Monitor" area chart showing how accuracy has changed over the past 30 days with a threshold line.
Screen 6 — Settings
Clean form-based layout with sections: Alert Thresholds (sliders for confidence threshold per model, toggle for email/Slack notifications), Pipeline Configuration (toggle cards to enable/disable each model, input for log source path), API Keys (masked input fields for integrations), and Appearance (though dark mode is fixed). Use a two-column layout with section headers and subtle dividers.
Additional design requirements:

Design for 1440px desktop width
Use a consistent left sidebar navigation with icons + labels, collapsible to icon-only mode
Every data visualization should use the same color system: electric blue for network, amber for system, red for anomaly, green for normal
Add realistic dummy data throughout — use actual feature names from CIC-IDS2017 (Flow Duration, Fwd Packet Length Mean, Flow Bytes/s) and HDFS event templates
Include hover states on all interactive elements
Use card components with subtle #30363D borders and 8px border radius
Include a loading skeleton state for the dashboard cards
